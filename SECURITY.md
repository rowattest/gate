# Security policy

rowattest-gate is a product of RW Digital Ventures LLC.

To report a security problem in this tool, use GitHub's private vulnerability reporting on this repository, or email info@rowattest.com. Please do not open a public issue for a security report.

Every report is read by the founder and receives a reply within 5 business days.

There is no bug bounty.

Scope: this repository, the rowattest-gate command line tool. For rowattest.com, app.rowattest.com, the REST API or the MCP server, see the policy at https://github.com/rowattest/.github/blob/main/SECURITY.md.
